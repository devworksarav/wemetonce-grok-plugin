# WeMetOnce Grok Plugin

WeMetOnce helps people find and reconnect with someone they remember from their past.

This Grok Build plugin connects to the public WeMetOnce MCP server and exposes only approved public Lost Connection posts.

## Capabilities

- Search approved public Lost Connection posts by name, location, school, college, relationship, profession, or memory.
- Retrieve an approved public Lost Connection post by its ID.
- Open matching posts on WeMetOnce.

## Privacy and safety

The MCP server is read-only. It does not expose private accounts, private messages, reports, credentials, or administrative data. Only information intentionally published in an approved public Lost Connection post is returned.
